# Система анализа эмоций в тексте
### Описание системы
Система представляет собой веб-приложение для анализа эмоций в тексте, пользователь может зарегистрироваться и авторизоваться. Тогда результаты его предыдущих анализов будут сохраняться в его истории.

### Развертывание системы

Для развертывания системы необходимо: Python(3.10+), pip, PostgreSQL, веб-браузер.

Для начала следует установить все зависимости, для этого нужно перейти в директорию App и в консоль ввести следующую команду:
```
pip install -r requirements.txt
```
После установки нужно открыть соединение в PostgreSQL с следующими параметрами:

- пользователь: emotion_user;
- пароль: password123;
- хост: 127.0.0.1 (localhost);
- порт: 5432;
- база данных: emotion_app.

Если хотите изменить параметры то в файле config.py следует изменить стандартную строку для подключения(DATABASE_URL) по следующему шаблону:
```
postgresql://<пользователь>:<пароль>@<хост>:<порт>/<база данных>
```
Это же нужно сделать и в конце метода get_database_url.

После чего можно запустить скрипт для инициализации БД (init_database.py):
```
py init_database.py
```

При успешной инициализации должны создаться таблицы users и text_analyses.

Для запуска системы запускаем главный скрипт:
```
py main.py
```
